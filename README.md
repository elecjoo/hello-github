# hello-github

A tiny starter repository created end-to-end through **LM Studio Bionic** and the official **GitHub MCP server**.

## What's here

| File | Purpose |
| --- | --- |
| `hello.py` | A small Python script to run locally |
| `LICENSE` | MIT License |

## Quick start

```bash
python hello.py
```

## How this repo was made

1. Repository created with the GitHub MCP `create_repository` tool
2. Files pushed in a single commit via `push_files`
3. A test issue opened with `issue_write`

_No human typing required — just an agent and a token._ 🤖
